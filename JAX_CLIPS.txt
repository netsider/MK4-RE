WHAT IS LISTED
Every clip number Jax's fighter object plays (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, and clips that turned up in his clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Some shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries
f0..f15 = fighter id). Jax takes entry f13 (PROVEN: throw 83/145, HK 66, LK 67, angled jump LK 59, close HP 263 all matched live).
Only the f13 entry is his; the other 15 entries are other fighters' clips. Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Jax vs P2 Jax (inactive dummy) and VS mode P1 Jax vs CPU opponents (memory logs;
Jax = select-screen index 6).
Frame sheets (8 frames per clip) of the captured video were checked by eye for 63 clips.

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Jax.
 GUESS        = weak evidence (static listing only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = pulled toward / behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Jax standing height -75169 (negative = up). "gap" = X distance set before the move.
 Sequences like 145-173-328 are the clips in the order they play.

 Fatality A (misc40, move word 2e014640, input F,F,D,F + LK RELEASE): REACHED live 3x, clips 384-443 / victim 389-400 (arm rip, PROVEN).
   Condition 0x2E (code 0x45E200) = X distance <= 65536 AND finish-him state AND (frame counter 0x538418 minus the time of
   the last LK PRESS, stored by the LK-press handler 0x45CD00 into 0x53FDBC) >= 240 frames. The frame counter runs at about
   60-64 per second, so LK must be held at least ~4 s before it is released. The opponent stays dazed only ~4 s, so the
   working input presses LK during the throw that ends the match (before FINISH HIM), keeps holding it, then at FINISH HIM:
   F,F,D,F, release LK (held ~4.7 s in total). Worked at gap 40000 (plain directions, and with BL held through the
   directions) and from gap 90000 (the F taps walk Jax in; the release distance was not logged).
   Failed: LK pressed at FINISH HIM next to the opponent (it plays close LK 30 and knocks the opponent down: round over);
   LK pressed at FINISH HIM at gap 90000-250000 and held 0.3-4.5 s (dazed time ran out, or the hold was too short);
   hold started too early for the window (5.0 s target: the dazed time ran out first).
 Fatality B (misc43, move word 1b413243, B,F,F,D+BL, condition 0x1B = X distance <= 65536): REACHED live 2x (gap 40000,
   pushed by the game to 34845), clips 555-556 / victim 557-206 (PROVEN). Both inputs worked: BL held through B,F,F,D,
   released, then BL pressed again; and the plain input (no Up in it, so nothing starts a jump).
 Stage fatalities: arena 0 (misc42, F,F,B+HP -> uppercut 293, static) and arena 8 (misc41, F,F,B+LK): not attempted (need those

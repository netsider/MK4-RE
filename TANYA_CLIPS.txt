WHAT IS LISTED
Every clip number Tanya's fighter object plays (as attacker OR as victim), every clip her own move scripts and
per-fighter tables point at, and clips that turned up in her clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Some shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries
f0..f15 = fighter id). Tanya takes entry f9 (PROVEN: intro 46, victory 124, throw 79/151, angled jump LK 58 all matched live).
Only the f9 entry is hers; the other 15 entries are other fighters' clips. Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Tanya vs P2 Tanya (inactive dummy) and VS mode P1 Tanya vs CPU opponents (memory logs).
Frame sheets (8 frames per clip) of the captured video were checked by eye for 53 clips.

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Tanya.
 GUESS        = weak evidence (static listing only).
 NOT HERS     = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in her set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = thrown behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).

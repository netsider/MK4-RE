LIU KANG (fighter id 3) - CLIP LIST AND STATUS
Mortal Kombat 4 PC (retail MK4.EXE). netsider's MK4-RE project. Built 2026-10-23 ET from the live memory logs
and the MK4.EXE static reading. Full detail: MK4_RE_NOTES_v3.txt (this repo), LIU KANG section.

WHAT IS LISTED
Every clip number Liu Kang's fighter object plays (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, and clips that turned up in shared clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Some shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries
f0..f15 = fighter id). Liu Kang takes entry f3 (PROVEN). Only the f3 entry is his; the other entries are other
fighters' clips (see "OTHER FIGHTERS' ENTRIES" at the end). Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Liu Kang vs P2 Liu Kang (inactive dummy) and VS mode P1 Liu Kang vs CPU opponents, including fatality runs (memory logs).
Select screen: Liu Kang is grid index 3 (row 0, column 3; the VS HUD then reads "LIU KANG") and the practice menu
reads "LIU KANG" (OCR). In VS the banner "LIU KANG WINS" is visible in the frames.
No clip in this list has a visual ID by eye from the owner yet; roles come from the input that played them (frame sheets checked by eye;
the renderer sometimes does not draw the fighters).

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Liu Kang.
 GUESS        = weak evidence (static listing only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = pulled toward / thrown behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Speeds are units/tick (1 tick ~ 1/60 s, PROVEN). Liu Kang standing height -70320 (negative = up).
 Sequences like 152-173-328 are the clips in the order they play.

WHAT IS LISTED
Every clip number Sub-Zero's fighter object plays (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, the clips of the old capture list, and clips that turned up in his sets but belong to
someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Some shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries
f0..f15 = fighter id). Sub-Zero takes entry f4 (PROVEN). Only the f4 entry is his; the other entries are other
fighters' clips (see "OTHER FIGHTERS' ENTRIES" at the end). Victim / reaction clips and weapon clips are shared.
Live sources: practice mode P1 Sub-Zero vs P2 Sub-Zero (inactive dummy; P2 victim clips are his too) and
VS/arcade mode P1 Sub-Zero vs CPU opponents (8 rounds won) (memory logs).

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live. "netsider confirmed" = he also checked it visually.
 NETSIDER-ID  = named by netsider from the clip viewer (DONE), in his words.
 LIKELY       = strong static (code) or indirect evidence, or PROVEN on another fighter for a shared clip, not
                seen live on Sub-Zero.
 GUESS        = weak evidence (static listing only, or the old mixed capture list only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = thrown behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Speeds are units/tick (1 tick ~ 1/60 s, PROVEN). Sub-Zero standing height -77660 (negative = up).
 Practice start gap 170392. Sequences like 153-173-328 are the clips in the order they play.

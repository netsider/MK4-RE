1. SETUP (PROVEN)
- MK4_nocd.EXE runs under Wine 10 (32-bit prefix) on a virtual 640x480x16 screen (Xvfb). No physical display or input is used.

- F: is a Wine CD-ROM drive holding DATA\M_*.ECM (the 277 MB ISO was too big to copy; the 4 menu videos are enough to boot).
- Keys (PROVEN via the Practice input display): U=HK J=LK T=HP G=LP SPACE=BL H=RN, W/Z/A/S = up/down/back/forward. Arrow keys drive Player 2's cursor; key "2" = Player 2 start.
- ESC switches the game to windowed mode (colours break on a 16-bit screen); avoid it.

2. CLIP ID FROM LIVE MEMORY (PROVEN)
- 0x521A64 = pointer the frame decoder (VA 0x4013A0) reads; 0x521A60 = frame; 0x521AA4 = frame count.

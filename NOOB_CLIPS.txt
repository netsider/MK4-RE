WHAT IS LISTED
Every clip number Noob's fighter object played live (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, and clips that turned up in shared clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries f0..f15).
Noob has id 17, past the 16 entries: the switch maps 17 to Reiko's entry f7 (PROVEN static; live HK 66, LK 67, sweep 62,
jump-up kick 61, jump LK 59, idle 284, intro 49, victory 113 all match Reiko's entries). His own clips differ from Reiko's in
the specials and in the close LK (Noob 41, Reiko 40). Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Noob vs P2 Noob (inactive dummy) and one VS run vs the CPU, memory logs; see HOW NOOB WAS SELECTED.

HOW NOOB WAS SELECTED (he is a hidden fighter, not on the normal grid or practice menu)
 Name table 0x4F11D8 has 18 names; 15 = GORO, 16 = KITANA, 17 = NOOB (PROVEN static).
 The practice menu cycles fighter ids 0..14 only in 0x4F11CC (P1) and 0x4F11D0 (P2); at practice start the code at
 0x4A3620 copies 0x4F11CC into the fight-time P1 fighter id 0x535EC8 (PROVEN static + live).
 Route used: FORCED FIGHTER ID IN MEMORY. With the practice menu open, 17 was written to 0x4F11CC and 0x4F11D0 (they read 3 / 3);
 the menu rows then read "PLAYER 1 NOOB SAIBOT" / "PLAYER 2 NOOB SAIBOT" and the fight started as Noob vs Noob (frames show two
 all-black ninjas; PROVEN). VS: see VS MODE below.
 The game's own route (static, code 0x4A0180, P1 select): with Hidden chosen ([0x53FD54] != 0), two buttons held (input bits
 0x4D30A4&0x20 and 0x4D30A8&4 clear), Noob unlocked ([0x5416AC] != 0), pick 7 (Reiko) and once-flag [0x5416B0] == 0, the id
 becomes 0x11 (17). Not tried live (LIKELY matches the public code: Hidden, then Reiko with RUN+BL).

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Noob.
 GUESS        = weak evidence (static listing only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 gap  = X distance between the fighters when the input starts.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = pulled toward / thrown behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Noob standing height -77660 (negative = up; the same as Reiko). Practice start X -85196 / +85196.
 Sequences like 154-172-328 are the clips in the order they play.

FATALITIES

 so there was nothing to try with the hold-Block method. Static stage-fatality rows exist: arena 0 (misc42) F,D,F+HK -> uppercut 293,
 and arena 8 (misc41) D,B,B+HK (clip not resolved) - LIKELY; not attempted (stage fatalities are on the deferred list for all fighters).
VS MODE
 VS route: FORCED FIGHTER ID IN MEMORY at the select screen. P1 picked Shinnok (grid index 2) in Arcade 1-player; for 3 s after
 the pick every value 6 in 0x535EC8 was overwritten with 17. The fight loaded as Noob Saibot: VS HUD "NOOB SAIBOT" vs "REPTILE",
 round banner "NOOB SAIBOT WINS" (PROVEN, frames).
 Result, one VS run (~245 s): Noob beat Reptile, Scorpion and Kai and reached Reiko (HUD names read from the frames, PROVEN).
 Round start: intro 49 every round (7 times, PROVEN). Round win: victory pose 113 (PROVEN).
 Throw: vs Reptile 80 -> P2 154-172 (2 times); vs Scorpion 76 -> P2 153-173 (once, round won). Both PROVEN live; why the throw
 clip changed with the opponent is not known (GUESS: picked by opponent id or by position).
 Noob as victim (VS): 199-13 (Scorpion spear 14), 152-173-328 (Scorpion throw 75), 131 / 185 (weapon throw 208), 128 (uppercut),
 192-194 (sweep), 311, 132, 157, 179, 182, 186-188, 195, 197, 586 (PROVEN, shared reaction clips).
 The VS driver keeps both fighters alive and sets the opponent HP to 400 before each throw, so rounds end on a throw or a hit.

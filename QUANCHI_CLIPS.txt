and the MK4.EXE static reading. Full detail: MK4_RE_NOTES_v3.txt (this repo), QUANCHI section.

WHAT IS LISTED
Every clip number Quan Chi's fighter object plays (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, and clips that turned up in his clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Some shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries
f0..f15 = fighter id). Quan Chi takes entry f8 (PROVEN). Only the f8 entry is his; the other 15 entries are other
fighters' clips (see "OTHER FIGHTERS' ENTRIES" at the end). Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Quan Chi vs P2 Quan Chi (inactive dummy) and VS mode P1 Quan Chi vs CPU opponents (memory logs).
No clip in this list has a visual ID by eye from the owner yet; roles come from the input that played them (frame sheets checked by eye).

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Quan Chi.
 GUESS        = weak evidence (static listing only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = thrown behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Speeds are units/tick (1 tick ~ 1/60 s, PROVEN). Quan Chi standing height -78643 (negative = up).
 Practice start X -85196 / +85196 (gap 170392). Sequences like 154-172-328 are the clips in the order they play.

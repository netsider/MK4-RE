GORO (fighter id 15) - CLIP LIST AND STATUS
Mortal Kombat 4 PC (retail MK4.EXE). netsider's MK4-RE project. Built 2026-10-23 ET from the live memory logs
and the MK4.EXE static reading. Full detail: MK4_RE_NOTES_v3.txt (this repo), GORO section.

WHAT IS LISTED
Every clip number Goro's fighter object played live (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, and clips that turned up in shared clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries f0..f15 = fighter id).
Goro takes entry f15 (the last entry; PROVEN live: 66, 67, 63, 327, 60 all match f15). Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Goro vs P2 Goro (inactive dummy), memory logs; see HOW GORO WAS SELECTED.

HOW GORO WAS SELECTED (he is a hidden fighter, not on the normal grid or practice menu)
 Name table 0x4F11D8 has 18 names; 15 = GORO, 16 = KITANA, 17 = NOOB (PROVEN static).
 The practice menu cycles fighter ids 0..14 only (max 0xE) in 0x4F11CC (P1) and 0x4F11D0 (P2); at practice start the code at
 0x4A3620 copies 0x4F11CC into the fight-time P1 fighter id 0x535EC8 (PROVEN static + live).
 Route used: FORCED FIGHTER ID IN MEMORY. With the practice menu open, 15 was written to 0x4F11CC and 0x4F11D0; the menu rows
 then read "PLAYER 1 GORO" / "PLAYER 2 GORO" (OCR) and the fight started as Goro vs Goro (frames show the four-armed Goro; PROVEN).
 The game's own route (static, code 0x4A0180, P1 select): after the pick, if [0x53FD54] != 0 (Hidden chosen), input bits
 0x4D30A4&0x20 and 0x4D30A8&4 are clear (two buttons held), [0x5416A4] != 0 (Goro unlocked) and the pick is 6 (Shinnok) and
 [0x5416A8] == 0, the fighter id becomes 15 and 0x5416A8 is set. Same for Noob: flags 0x5416AC/0x5416B0 with Reiko (7) -> 0x11.
 P2 copy at 0x4A0490 (0x538268 / 0x536060). Public FAQs give the player code (beat the game with Shinnok to unlock, then Hidden,
 U,U,U,L on Shinnok, RUN+BL) - not tried in full (LIKELY match). Setting the flags in memory and picking Shinnok did not give Goro.

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Goro.
 GUESS        = weak evidence (static listing only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 gap  = X distance between the fighters when the input starts.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = pulled toward / thrown behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Goro standing height -85458 (negative = up; Liu Kang -70320, so Goro stands 15138 higher - he is the big fighter).
 Practice start X -85196 / +85196. Sequences like 606-607-152-173-328 are the clips in the order they play.

FATALITIES
 Goro has no fatality entries: the decoder found no misc40 / misc43 (fatality A / B) rows and no stage-fatality rows for
 fighter 15 (PROVEN static). He is a boss / hidden fighter. No fatality runs were made.
VS MODE
 VS route: FORCED FIGHTER ID IN MEMORY at the select screen. P1 picked Shinnok (grid index 2) in Arcade 1-player; for 3 s after
 the pick every value 6 in 0x535EC8 was overwritten with 15. The fight loaded as Goro: VS HUD "GORO" vs "REPTILE", round banner "GORO WINS" (PROVEN).
 (First tries: writing 0x53FD54 = 1, 0x5416A4 = 1, 0x5416A8 = 0 before the pick, with and without BL+RUN held (input bits
 0x4D30A4 0x20 and 0x4D30A8 4 then read clear), still loaded Shinnok: 0x535EC8 stayed 6. So 0x4A0180 alone was not the
 path taken for that pick; GUESS: 0x53FD54 is reset or the Hidden choice is a separate select step.)
 Result, one VS run (150 s): Goro beat Reptile 2-0, then won round 1 against Scorpion; each won round was
 throw 604-605-75 then victory pose 594 (3 times, PROVEN). Round start: Goro played no intro clip (idle 587 straight away; intro switch 0x4E8EE0 f15 has no clip) - LIKELY.
 Goro as victim (VS): 199-13 (spear pull), 311, 134. No "FINISH HIM" sequence was reached on Goro's side (rounds were won by
 throw with the opponent HP set low; the logger sets the opponent HP, see the PROVEN table).

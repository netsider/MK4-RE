RAIDEN (fighter id 1) - CLIP LIST AND STATUS
Mortal Kombat 4 PC (retail MK4.EXE). netsider's MK4-RE project. Built 2026-10-23 ET from the live memory logs
and the MK4.EXE static reading. Full detail: MK4_RE_NOTES_v3.txt (this repo), RAIDEN section.

WHAT IS LISTED
Every clip number Raiden's fighter object plays (as attacker OR as victim), every clip his own move scripts and
per-fighter tables point at, and clips that turned up in his clip sets but belong to someone else.
Clip number = index into the game's 612-entry clip table (record address 0x4FDD6C + 12*clip).
Some shared move scripts pick the clip per fighter with a 16-entry FIGHTER_SWITCH (script opcode 0x3C, entries
f0..f15 = fighter id). Raiden takes entry f1 (PROVEN: intro 47, victory 123, throw 80/154, angled jump LK 59 all matched live).
Only the f1 entry is his; the other 15 entries are other fighters' clips. Victim / reaction clips are shared by all fighters.
Live sources: practice mode P1 Raiden vs P2 Raiden (inactive dummy) and VS mode P1 Raiden vs CPU opponents (memory logs).
Frame sheets (8 frames per clip) of the captured video were checked by eye for 50 clips.

STATUS LABELS
 PROVEN       = seen live in the running game (memory log of the clip slot while pressing the input), or read
                directly in the game code and matched live.
 LIKELY       = strong static (code) or indirect evidence, not seen live on Raiden.
 GUESS        = weak evidence (static listing only).
 NOT HIS      = belongs to another fighter (or is another fighter's version of a shared move). The evidence
                column says how sure (PROVEN or LIKELY).
 UNKNOWN      = in his set, purpose not known.

UNITS (raw game units only)
 Positions are 16.16 fixed point: 65536 = 1 game unit = 256 mesh units (PROVEN). No metres are used.
 dx   = victim X net displacement over the reaction (last - first). + = pushed away from the attacker,
        - = pulled toward / behind the attacker.
 rise = victim standing height minus its lowest height (how high it went).
 Raiden standing height -75497 (negative = up). "gap" = X distance set before the move.
 Sequences like 154-172-328 are the clips in the order they play.
